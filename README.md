# 🌐 WebServer  

**WebServer** is a minimal HTTP server implemented in **C++**, capable of handling basic HTTP requests and serving static content.  
## 🎯 Objectives

- Implement a simple **HTTP server** in C++
- Handle **GET**, **POST** and **DELETE** requests.  
- Support **persistent connections** and **response headers**  
- Learn about **sockets, TCP/IP, and multi-client handling**  
- Understand **server architecture and request parsing**
  
🛠️ Build & Run  
make  
update the config file to match your config.
./webserver config.test  
in your navigator :  `http://<ip>:<port>/<site_name>/`
